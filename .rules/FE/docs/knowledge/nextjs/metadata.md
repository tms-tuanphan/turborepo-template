# Metadata

**When to use:** Page titles, OG tags, robots — export `metadata` or `generateMetadata` from layouts/pages.

**Repo pattern:**

- Root `app/layout.tsx` defaults; segment overrides in route layouts
- Keep strings i18n-ready when page is localized — [fe-i18n.mdc](../../../rules/fe-i18n.mdc)
